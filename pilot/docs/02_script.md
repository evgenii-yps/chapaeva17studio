# Сценарий урока (пилот)

Исходник не содержит речи, поэтому **текст озвучки не сочиняется** (правило ТЗ: не выдумывать технику). Сценарий = структура ролика + нейтральные субтитры, описывающие видимое движение (факт, с тайм-кодами исходника).

| Блок | Тайм-код | Содержание | Источник |
|---|---|---|---|
| Титул | 0:00–0:04 | «Цигун» — титр исходника; пометка «Пилот. Внутренний тест» | титр видео ≈4–8 с (факт) |
| Фазы 1–12 | 0:00–0:55 | Движение персонажа повторяет исходник 1:1 по времени; субтитры — краткое описание фазы из `02_catalog.md` | видео, кадры 1/с |
| Звук | весь ролик | исходная звуковая дорожка (музыка) — запасной путь: TTS не запущен (нет модели, нет текста подсказок) | исходник |

Вступление/заминка по ТЗ (≤20 с каждое) отдельно не добавлялись: ролик на 55 с уже содержит начало и завершение (стойка → стойка), добавлять к ним слова без исходной речи значит выдумывать содержание.
