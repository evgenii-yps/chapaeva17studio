# Этап 3. Захват движения — отчёт

## Методы
| Метод | Статус | Причина |
|---|---|---|
| **A. MediaPipe PoseLandmarker (heavy), world landmarks + 2D** | **выполнен, используется** | веса доступны (storage.googleapis.com), работает на CPU: 1665 кадров за ~100 с (~17 кадр/с) |
| **B. SMPL/SMPL-X (WHAM, 4D-Humans/HMR2 или аналог)** | **не выполнен** | требует весов с huggingface.co и модели SMPL (отдельная регистрация/лицензия MPI, некоммерческая). Хост Hugging Face закрыт сетевой политикой среды в течение всей сессии (проверялось 00:52, 01:01, 01:03, 02:14 и около 04:15 UTC — 403). Запасной путь по инструкции: оставить только MediaPipe |

**Вывод:** сравнение двух методов, которого требует ТЗ, в пилоте **не проведено**. Это главное ограничение этапа: у метода A нет проверки на независимом методе. `[ПРЕДПОЛОЖЕНИЕ]` SMPL-метод, вероятно, точнее по глубине и скруткам (он использует модель тела), но в пилоте это не проверено.

## Конвейер (`work/mocap/`)
1. `extract_mediapipe.py` — позы по кадрам (2D-ориентиры + world 3D, visibility).
2. `build_bvh.py` — постобработка и экспорт BVH:
   - замена повёрнутых кадров 0–3 исходника (склейка) удержанием первой нормальной позы;
   - коррекция перепутанных лево/право (12 кадров: 14.6–14.93 с и 25.17 с);
   - интерполяция точек с visibility ≤ 0.5; сглаживание One Euro + Savitzky–Golay;
   - **гибрид (версия v3):** x, y — из 2D-ориентиров кадра (точнее в плоскости камеры), глубина z — из world-координат MediaPipe;
   - фиксированные длины костей (медианы по world-координатам); ориентации костей по направлениям сегментов, таз/грудь/голова — по линиям бёдер/плеч/ушей;
   - контакт с полом: самая низкая точка стоп = Y=0; корень X — из положения таза в кадре, корень Z — фиксация опорных стоп с вычитанием дрейфа.
3. `viz_skeleton.py` — визуальный контроль (скелет рядом с кадром).

## Известные дефекты (факты, измерено/увидено)
- Остаточный наклон корпуса «к камере» на прямой стойке ≈ 6–11° (depth-bias world-координат MediaPipe). Попытка исправить поправкой тангажа по длине торса (ограничение длины + проекция) **ухудшила** результат (наклон вырос до 17–20° из-за чувствительности к перспективному масштабу) и отвергнута (решение D10).
- Скольжение стоп ~0.2 м/с в среднем (опорные стопы); визуально заметно на сменах опоры.
- Кисти/пальцы не восстановлены, скрутка предплечий — нулевая (swing без твиста); колени/локти — по направлению сегментов, твист отсутствует.
- Одна камера, профильные ракурсы: глубина приблизительная; на безликом манекене повторная детекция MediaPipe сама путает лево/право (см. QA).
- Углы локтей и коленей в BVH совпадают с эталоном по построению (длины костей фиксированы, углы сохраняются) — этот показатель тавтологичен и точность относительно реального тела не доказывает.
