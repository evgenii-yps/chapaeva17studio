# Чапаева 17 — сайт-визитка

Одностраничный лендинг студии движения «Чапаева 17» (Санкт-Петербург, Петроградский район).
Чистая статика — HTML / CSS / vanilla JS — плюс одна serverless-функция для приёма заявок в Telegram. Деплой на Vercel.

## Структура

```
/
├── index.html              # лендинг (все секции)
├── privacy.html            # политика конфиденциальности (152-ФЗ)
├── styles.css              # дизайн-система и вёрстка
├── script.js               # навигация, анимации, лайтбокс, отправка формы
├── api/
│   └── submit.js           # serverless: заявка → Telegram Bot API
├── public/images/          # изображения (jpg + webp), см. images/README.md
├── docs/                   # превью-скриншоты секций
├── vercel.json             # cleanUrls, без trailingSlash
└── package.json            # метаданные (зависимостей нет, fetch встроен в Node 18+)
```

## Локальный запуск

Статику можно открыть любым статик-сервером из корня репозитория:

```bash
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

Форма при локальном запуске без Vercel вернёт ошибку сети на шаге `/api/submit` — это нормально,
serverless-функция работает только в окружении Vercel (или `vercel dev`).

## Деплой на Vercel

1. **Привязать репозиторий.**
   - Зайдите на https://vercel.com → **Add New… → Project** → импортируйте репозиторий `chapaeva17studio`.
   - Framework Preset: **Other** (это чистая статика, сборка не нужна).
   - Build Command — пусто; Output Directory — пусто (корень репозитория).

2. **Задать переменные окружения.**
   В настройках проекта → **Settings → Environment Variables** добавьте (scope: Production + Preview):

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather (НЕ коммитить в репозиторий) |
   | `TELEGRAM_CHAT_ID` | `-1003938123716` (канал «ЗАЯВКИ САЙТ ЧАПАЕВА17») |

   Бот должен быть добавлен в канал как администратор с правом отправки сообщений.

3. **Deploy.** После пуша в ветку Vercel соберёт проект автоматически.

### Проверка работы формы

Через браузер: заполнить форму на сайте → в канале появится сообщение «🔔 Новая заявка с сайта».

Через `curl` (замените домен на свой):

```bash
curl -X POST https://chapaeva17studio.vercel.app/api/submit \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","phone":"+79991234567","channel":"Telegram","direction":"Пилатес на матах","comment":"проверка"}'
# ожидаемый ответ: {"ok":true}
```

Если приходит `{"ok":false,"error":"Сервис временно недоступен"}` — не заданы env-переменные.

## Защита формы

- honeypot-поле `_honey` (скрыто от людей; если заполнено — заявка тихо игнорируется);
- проверка времени: отправка быстрее 2 секунд после загрузки считается ботом.
