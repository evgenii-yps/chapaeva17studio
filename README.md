# Чапаева 17 — сайт-визитка

Одностраничный лендинг студии движения «Чапаева 17» (Санкт-Петербург, Петроградский район).
Чистая статика — HTML / CSS / vanilla JS. Запись ведётся виджетом YClients (iframe). Деплой на Vercel.

## Структура

```
/
├── index.html              # лендинг (все секции)
├── privacy.html            # политика конфиденциальности (152-ФЗ)
├── styles.css              # дизайн-система и вёрстка
├── script.js               # навигация, анимации, лайтбокс
├── public/images/          # изображения (jpg + webp), см. images/README.md
├── docs/                   # превью-скриншоты секций
├── vercel.json             # cleanUrls, без trailingSlash
└── package.json            # метаданные (зависимостей нет)
```

## Локальный запуск

Статику можно открыть любым статик-сервером из корня репозитория:

```bash
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

## Деплой на Vercel

1. **Привязать репозиторий.**
   - Зайдите на https://vercel.com → **Add New… → Project** → импортируйте репозиторий `chapaeva17studio`.
   - Framework Preset: **Other** (это чистая статика, сборка не нужна).
   - Build Command — пусто; Output Directory — пусто (корень репозитория).

2. **Deploy.** После пуша в ветку Vercel соберёт проект автоматически. Переменные окружения не нужны.

## Запись (YClients)

Запись ведётся виджетом YClients, встроенным через `<iframe>` в секции «Запись» (`#booking`):
`src="https://n1727175.yclients.com"`. Серверная часть на стороне YClients — собственного
бэкенда/serverless у сайта нет. Чтобы поменять филиал/форму — обновите `src` iframe в `index.html`.

## Изображения

Все изображения лежат в `public/images/` с WebP-версиями и JPG-фоллбэком (`<picture>`).
Полная карта файлов с описаниями — в [`public/images/README.md`](public/images/README.md).
Исходники (оригиналы с телефона, архивы) хранятся локально в `_materials_tmp/` и не коммитятся (`.gitignore`).
